# Explicación de métodos del proyecto

- **main**  
  Punto de entrada del programa. Crea el objeto principal y llama al menú con `init()`.

- **init**  
  Muestra el menú principal y gestiona las opciones del usuario en bucle.

- **crearCarpeta**  
  Preparado para crear la carpeta de archivos. Aún no implementado.

- **cargarViajes**  
  Pensado para cargar viajes desde archivos previos. Está vacío por ahora.

- **leerViajeArchivo**  
  Leerá un archivo `.txt` y añadirá sus datos a las listas. Método declarado pero sin lógica aún.

- **planificarViaje**  
  Pide datos al usuario, muestra un resumen y guarda si el usuario confirma.

- **guardarEnArchivo**  
  Guardará los datos del viaje en un archivo `.txt`. Declarado pero sin implementación.

- **mostrarViajes**  
  Lista todos los viajes registrados mostrando ciudad, país e ID.

- **mostrarDetallesViaje**  
  Muestra toda la información completa de un viaje específico.

- **generarInforme**  
  Método vacío que servirá para crear un informe de viajes.

- **eliminarViaje**  
  Elimina un viaje de las listas y su archivo asociado.

- **leerNumero(int min, int max)**  
  Lee un número desde consola, valida que esté dentro de un rango.

- **leerDecimal**  
  Lee un número decimal desde consola y lo convierte a `double`.
